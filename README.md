# Renata – Personal Profile Page

## About this project
This is a simple personal profile page introducing who I am in a clean and friendly way.
The page includes a short introduction, a photo, my interests, and links to my social media.

My goal is to keep the design minimal, soft, and easy to read while learning the basics of web development.

The page will gradually evolve as I continue improving my skills.

You are welcome to explore it!
